# Как редактировать блог (без разработчика)

Репозиторий: https://github.com/AlexandeRadyshevsky/web_agency
Все статьи лежат в папке `blog/`. Сайт на Vercel обновляется автоматически через ~1 минуту после любого изменения в ветке `main`.

Есть два способа: через сайт GitHub (проще, без терминала) и через git в терминале.

---

## Способ 1 — через сайт GitHub (рекомендуется для SEO)

### Отредактировать существующую статью

1. Зайти на https://github.com/AlexandeRadyshevsky/web_agency/tree/main/blog
2. Открыть нужный файл, например `how-to-remove-negative-google-reviews.html`
3. Нажать значок карандаша **"Edit this file"** (справа сверху)
4. Менять только текст между тегами — `<h2>...</h2>`, `<p>...</p>`, `<li>...</li>`. Сами теги (угловые скобки) не трогать, иначе верстка сломается.
5. Внизу страницы: **Commit changes** → короткое описание изменения → **Commit directly to the `main` branch** → Commit.
6. Готово, через минуту изменения будут на сайте.

### Добавить новую статью

1. Открыть `blog/_template.html`, нажать **Copy raw file** (или скачать).
2. В папке `blog/` создать новый файл через **Add file → Create new file**.
   Имя файла = "slug" статьи: только латиница в нижнем регистре, слова через дефис, без пробелов и без точек/акцентов.
   Пример: `blog/kak-otvechat-na-negativnye-otzyvy.html`
3. Вставить в него содержимое шаблона и отредактировать места, помеченные `<!-- EDIT -->`:
   - `<title>` и `<meta name="description">` — для Google (title + короткое описание)
   - `lang="en"` в теге `<html>` — поставить `"it"`, если статья на итальянском
   - категория и дата в `<div class="art-meta">`
   - заголовок в `<h1>`
   - сам текст статьи внутри `<article class="post-body">` — обычный HTML: `<h2>`, `<p>`, `<ul><li>`, `<strong>`, `<a href="...">`
4. Commit changes прямо в `main`.
5. Открыть `blog/posts.json`, нажать Edit. Скопировать один существующий блок `{ ... }` и добавить его в начало или конец массива (не забыть запятую между блоками, без запятой после последнего элемента). Заполнить поля:

   | Поле | Что писать |
   |---|---|
   | `slug` | точно как имя файла, без `.html` |
   | `date` | `ГГГГ-ММ-ДД` |
   | `lang` | `"en"` или `"it"` |
   | `category` | `{ "en": "...", "it": "..." }` |
   | `title` | `{ "en": "...", "it": "..." }` |
   | `excerpt` | 1 предложение-анонс, `{ "en": "...", "it": "..." }` |
   | `cover` | путь к обложке, например `"blog/cover-reviews.jpg"`, или `""` если без обложки |

   Если добавляете обложку — сначала загрузите картинку в папку `blog/` (Add file → Upload files).
6. Commit changes → статья появится в списке на `/blog.html`.

**Важно:** `posts.json` должен оставаться валидным JSON. Если не уверены — после сохранения открыть https://jsonlint.com и вставить содержимое файла, чтобы проверить на ошибки.

## Способ 2 — через терминал (если умеете git)

```bash
git pull
# отредактировать файлы в blog/
git add .
git commit -m "blog: <что изменили>"
git push
```

---

## Чего не трогать

- `styles.css` и `blog/article.css` — общий дизайн сайта, менять только если нужно поменять стиль, а не контент.
- Структуру тегов внутри статьи (`<article class="post-body">` и т.д.) — можно менять только текст внутри тегов.
- Поле `slug` в `posts.json` должно **всегда** совпадать с именем файла статьи.
